# SubCraft v0.2.4

## New

- **English UI** — the whole desktop interface (dialogs, progress, errors) is now in English; code comments stay Chinese.
- **NVIDIA Parakeet engine** — new local transcription engine via ONNX Runtime (no PyTorch):
  - `Parakeet TDT 0.6B v2` — English only, top of the Open ASR leaderboard
  - `Parakeet TDT 0.6B v3` — 25 European languages, auto language detection
  - int8 quantized, CPU-friendly; word-level timestamps feed the same subtitle resegmentation as faster-whisper
- **Language hints for every model** — hovering a model in the Transcribe/Batch dialogs shows which languages it is good at.
- **Batch mode in the desktop UI** — process a whole folder (transcribe → optional translate → export SRT/ASS/soft/hard video), with resume (finished files are skipped on re-run) and a JSON report, shared with the CLI/MCP pipeline.
- **Task cancellation** — running tasks (transcribe/translate/export/batch) can be cancelled from the progress overlay; ffmpeg is killed immediately.
- **Export ETA** — the progress overlay estimates remaining time.
- **Drag & drop import** — drop a video file anywhere on the window to import it.
- **Remembered choices** — transcribe engine/model/language, translate target/provider, export format & mode, batch options and last output directory are all persisted.
- **Inline export/batch progress bars** — percentage + live ffmpeg message inside the dialogs.

## Fixes

- Export dialog now shows a real progress bar (the video-area overlay was hidden behind the dialog).
- Model/engine/language choices in the transcribe dialog are saved (previously read-only).
- Windows/Linux assets now bundle the onnx-asr engine and the batch router.

## Notes

- First use of Parakeet downloads the model (~230 MB int8) automatically.
